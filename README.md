# Java Back-end Studies

Repositório de estudos e prática em desenvolvimento back-end com Java.

O objetivo aqui é registrar minha evolução de forma organizada, com exercícios, pequenos projetos e implementações feitas ao longo da faculdade e da formação complementar em Java.

## Foco atual

- Fundamentos da linguagem Java
- Lógica de programação e algoritmos
- Programação orientada a objetos
- Git e GitHub
- SQL e modelagem de dados

## Próximos tópicos

Conforme o avanço dos estudos, o repositório também deve incluir:

- Collections e generics
- Tratamento de exceções
- Testes automatizados
- APIs REST
- Spring Boot
- Persistência de dados
- Projetos back-end completos

## Organização

A estrutura será criada conforme houver código real para cada assunto, evitando pastas vazias ou exemplos adicionados apenas para preencher portfólio.

Cada exercício ou projeto deve conter contexto suficiente para identificar o que está sendo praticado e, quando necessário, instruções para execução.
